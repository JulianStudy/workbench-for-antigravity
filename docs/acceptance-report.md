# Workbench 本机原型验收记录

开发验收使用 Antigravity 桌面 App 2.34.0、`agy` CLI 1.5.16，以及 App 内置的 Node.js v24.22.0。

| 检查项 | 开发验收记录 |
| --- | --- |
| 侧栏加载与通信 | 示例项目返回 `workbench-ok`，显示正确的检查目录。 |
| 通过 | 点击运行后显示「通过」，退出码为 `0`。 |
| 失败 | 修改示例实现使断言失败，侧栏显示「失败」、退出码 `1` 和断言摘要。 |
| 自动过期 | 从通过版本出发，仅修改一条源码注释，侧栏在 5 秒内显示「已过期」并保留上次通过的证据。重跑后恢复「通过」。 |
| 持久化 | 重跑后在新会话打开侧栏，读回同一次已完成检查的时间和证据。 |
| 干净副本 | 阶段 1 在刷新 MCP 服务并触发新会话轮次后确认路径正确。阶段 4 交付包在干净副本里重新安装并通过 CLI 严格校验。 |

阶段 4 的记录覆盖干净副本的重新安装和严格校验。三种状态的桌面实测记录来自原示例项目。

切换两个装有同名插件的工作区时，App 2.34.0 可能复用先前的 MCP 服务。运行前请检查侧栏显示的目录。如果仍显示原工作区，重启 App 后在目标工作区重新打开侧栏。
